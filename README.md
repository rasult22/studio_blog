# Дурак - Карточная игра онлайн

Классическая карточная игра "Дурак" с мультиплеером на WebSocket.

## Особенности

- Мультиплеер до 6 игроков
- Классическая колода 36 карт (от 6 до туза)
- Красивый игровой интерфейс
- Комнаты с кодами для приглашения друзей
- Адаптивный дизайн для мобильных устройств

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start
```

Откройте http://localhost:3000 в браузере.

## Правила игры

1. Каждому игроку раздаётся по 6 карт
2. Козырь определяется последней картой в колоде
3. Первым ходит игрок с младшим козырем
4. Атакующий кладёт карту, защитник должен побить старшей картой той же масти или козырем
5. Можно подкидывать карты того же достоинства, что есть на столе
6. Если защитник не может побить - забирает все карты
7. Если отбился - карты идут в отбой
8. Проигрывает тот, у кого остались карты в конце игры

## Технологии

- Node.js + Express
- WebSocket (ws)
- Vanilla JavaScript
- CSS3 с анимациями
